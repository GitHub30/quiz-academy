# Quiz Academy — Claude 認定 対策クイズ学院

Claude 認定(Claude Certified Architect – Foundations)の出題分野を、対戦形式のクイズで学べる非公式の学習ゲームです。
インストールできる PWA で、一度開けばオフラインでも遊べます。

**プレイ:** https://github30.github.io/quiz-academy/

## 遊び方

| モード | 内容 |
| --- | --- |
| 🏆 学院トーナメント | 12 人(自分 + CPU 11 人)の勝ち抜き戦。予選(上位 8 人通過)→ 準決勝(上位 4 人)→ 決勝。早く正解するほど高得点 |
| 📖 修練 | 分野・問題数を選ぶ練習モード。間違えた問題だけの復習もできる |
| 🎓 模擬検定 | 本試験の配点比率に合わせた 20 問。1000 点満点に換算し 720 点で合格 |
| 📊 成績と設定 | 分野別の正答率、階級、プレイヤー名 |

出題形式は 8 種類: ○× / 四択 / 連想 / 複数選択 / 順番当て / 線結び / タイピング / 文字パネル。

## 出題分野

| 分野 | 配点比率 |
| --- | --- |
| エージェントアーキテクチャとオーケストレーション | 27% |
| ツール設計と MCP 統合 | 18% |
| Claude Code の設定とワークフロー | 20% |
| プロンプトエンジニアリングと構造化出力 | 20% |
| コンテキスト管理と信頼性 | 15% |

問題はすべてこのリポジトリのために独自に作成したもので、実際の試験問題ではありません。
本アプリは Anthropic とは無関係の非公式ツールです。

## 開発

ビルド不要の静的サイトです(依存パッケージなし)。

```sh
npm start                 # http://localhost:8080 で起動
npm test                  # 問題データとゲームロジックの検証
node scripts/e2e.mjs      # ブラウザ通しテスト(Playwright と、ポート 8765 のローカルサーバーが必要)
```

- `js/questions.js` — 問題データ(形式はファイル冒頭のコメント参照)
- `js/engine.js` — 判定・採点・CPU などの純粋なロジック
- `js/app.js` — 画面
- `sw.js` / `manifest.webmanifest` — PWA

## デプロイ

`.github/workflows/pages.yml` が検証のあと GitHub Pages へデプロイします。
初回のみ、リポジトリの Settings → Pages → Build and deployment の Source を **GitHub Actions** にしてください。
